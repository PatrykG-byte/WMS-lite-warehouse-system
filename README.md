# WMS-lite Warehouse System

A local warehouse workflow system built to support inbound, stock control, picking, packing, outbound handling and audit history.

The project was created as a practical operations tool for controlling warehouse processes, reducing manual checks and improving traceability.

## Purpose

WMS-lite helps manage operational warehouse workflows where stock, orders, pallets, boxes and exceptions need to be tracked in one local system.

The system focuses on:

- inbound receiving
- current stock visibility
- picking workflow
- packing workflow
- outbound pallet and box control
- missing / extra / damaged item handling
- audit history
- user permissions

## Tech Stack

- Python
- Streamlit
- SQLite
- pandas
- Microsoft Excel / CSV data processing

## Project Type

Portfolio case study based on a real warehouse operations system.

Production data, company identifiers and internal files are not included.
