# Permissions Model

The system uses role-based access to separate operational and administrative actions.

## Example Roles

- Admin
- Supervisor
- Leader
- Operator
- Viewer

## Example Permissions

- view current stock
- receive deliveries
- release deliveries
- create picking plans
- perform picking
- perform packing
- edit packed outbound data
- manage users
- view audit history
- create backups

Permissions are designed to reduce accidental changes and protect critical workflows.
