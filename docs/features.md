# Features

## Inbound

- Delivery plan import
- Receiving goods into pending stock
- Validation against planned quantities
- Extra / damaged item classification
- Delivery closing workflow

## Current Stock

- Stock view by PN, pallet, box, country and status
- Filtering by operational status
- Separation between pending, available, picked and packed stock

## Picking

- Picking plan creation
- Item allocation from available stock
- Missing item handling
- Reassignment from alternative sources
- Picking history

## Packing

- Packing picked items into outbound pallets and boxes
- Partial packing support
- Box-only shipment mode
- Packing list preview

## Outbound

- Outbound pallet and box tracking
- Search by order, country, pallet or box
- CSV export support

## Audit History

- Tracking of operational changes
- Operator actions
- Before / after values
- Problem-solving support
