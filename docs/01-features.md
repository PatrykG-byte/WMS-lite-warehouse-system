# Features

## Inbound

- Delivery plan import
- Receiving flow
- Pending stock handling
- Extra and damage classification
- GAP comparison between plan and received stock

## Stock

- Current stock overview
- Product number tracking
- Pallet and box tracking
- Country/status filtering
- Stock status model
- Stock recalculation

## Picking

- Picking plan creation
- Picking execution
- Source pallet and box tracking
- Shortage detection
- Alternative source reassignment

## Packing

- Packing picked items
- Outbound pallet and box assignment
- Standalone box shipping
- Partial packing / split quantity
- Packing list support

## Problem Solving

- Missing handling
- Extra handling
- Damage handling
- Product found outside stock
- Full stock record correction
- Return from PACKED to PICKED
- Transfer between outbound pallets/boxes

## Audit

- Stock correction history
- Operator tracking
- Operation type tracking
- Old/new value tracking
- Station tracking

## Access Control

- User login
- Roles
- Permissions
- Admin panel
