# Workflow Overview

## 1. Inbound

Goods are received from delivery plans and registered into the system as pending stock.

After validation, the delivery can be released into available stock.

## 2. Stock Control

Available stock is visible by product number, country, pallet, box and status.

The system separates stock that is available, pending, picked, packed, missing, damaged or extra.

## 3. Picking

A picking plan is created for an outbound order.

Operators pick items from available stock. If an item is missing, the system supports reassignment from alternative stock sources.

## 4. Packing

Picked items are packed into outbound pallets and boxes.

The system supports partial packing, allowing one product quantity to be split across multiple outbound units.

## 5. Outbound

Packed items are prepared for shipment.

Outbound pallets and boxes can be searched, reviewed and exported.

## 6. Audit

Operational changes are recorded in history to support traceability and problem solving.
