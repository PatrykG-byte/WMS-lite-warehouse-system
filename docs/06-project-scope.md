# Project Scope

### Public portfolio version boundaries

## Purpose

This repository presents WMS-lite as a portfolio case study of a warehouse operations system.

It shows the process logic, workflows, database-backed stock control, permissions, correction handling and audit approach.

## What This Repository Shows

- inbound receiving,
- stock status control,
- picking,
- packing,
- outbound pallet / box assignment,
- problem solving,
- stock record correction,
- permissions,
- audit history,
- SQLite-backed process logic,
- Streamlit UI structure.

## What This Repository Does Not Include

This public repository does not include real operational data.

Excluded from the repository:

- production database files,
- real delivery files,
- real order files,
- real customer or supplier data,
- employee data,
- backups,
- logs,
- secrets or credentials.
